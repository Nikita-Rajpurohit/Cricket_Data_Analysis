Cricket Data Analysis – T20 World Cup 2022

An end-to-end sports analytics project that leverages web scraping, data transformation, and visualization to derive insights from the T20 World Cup 2022.

Project Overview

This project encompasses the complete data analysis pipeline:

- Data Collection: Utilized Bright Data for web scraping to gather match and player statistics.
- Data Transformation: Processed and cleaned data using Python and pandas.
- Data Visualization: Created interactive dashboards in Power BI to present insights.

The objective is to provide a comprehensive analysis of the T20 World Cup 2022, highlighting key performances and trends.

Repository Structure

The repository is organized as follows:

- `web_scrapping_codes.zip`: Contains scripts used for data extraction.
- `t20_json_files.zip` & `t20_csv_files.zip`: Raw data files in JSON and CSV formats.
- `t20_data_preprocessing.ipynb`: Jupyter notebook for data cleaning and transformation.
- `DAX Measures and Calculated columns.xlsx`: Details of DAX formulas used in Power BI.
- `t20_cric_1_power_query.pbix`, `Stage-2.pbix`, `Stage-3.pbix`, `Codebasics Cricket Best 11.pbix`: Power BI dashboard files showcasing various analytical perspectives.

Technologies Used

- Web Scraping: Bright Data
- Data Processing: Python, pandas
- Data Visualization: Power BI

Key Insights

The analysis provides:

- Top-performing players and teams.
- Match-by-match performance breakdowns.
- Comparative analysis of batting and bowling statistics.
- Visual representations of key metrics and trends.
